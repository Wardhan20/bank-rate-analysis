# UK Interest Rates, 1975–2026

A data science project looking at 50 years of the Bank of England's interest rate.

## Dataset

- **Name:** Bank Rate history
- **Published by:** Bank of England
- **Licence:** Open Government Licence (free to use and share)
- **Time period:** January 1975 to November 2026
- **File:** `data/boe_bank_rate.csv`

Each row is one change to the interest rate. It has two columns:
the date of the change and the new rate.

## Why it matters

Bank Rate is the main interest rate in the UK. When it goes up,
mortgages and loans get more expensive and savings earn more.
When it goes down, the opposite happens. So it affects almost everyone.

## Questions

1. How has the interest rate changed over the last 50 years?
2. Did the Bank of England change rates differently after it
   became independent in 1997?
3. How unusual were the rate rises between 2021 and 2023?

## How to run

1. Install Python with these libraries: pandas, numpy, matplotlib, seaborn
2. Open `cgbank_rate_analysis.ipynb` in JupyterLab
3. Click **Kernel → Restart Kernel and Run All Cells**
